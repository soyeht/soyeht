# Reports

Dated measurements that a gate check, a source comment or an ADR still points to. They record
what was true on their date and are not checked against the current protocol
(`scripts/check_doc_names.py`). Older reports are in `docs/archive/`.

| File | What it is |
| --- | --- |
| `pane-layout-floor-measurements.md` | The content rulers behind the pane layout floors (`PaneLayoutFloors.swift`). |
| `package-sizes-2026-11-02.md` | The size of each shipping package (`scripts/package_sizes.json`, `docs/platforms.md`). |
| `prose-rendering-spike.md` | The rendering probe behind ADR 0061. |
| `writing-chrome-e1.md`, `-e2.md`, `-e3.md` | Validation of the writing chrome. |
| `evidence/` | The data behind ADR 0069. |
