# New-pane chooser floor

Date: 2026-09-19. Scope: the provisional `NewPaneSheet` leaf used by the macOS
rewrite. The ruler is generated by `scripts/measure_pane_floors.swift`; it uses
the same registered fonts and 15 pt pane halo as the other measured floors.

## Fixture and method

The complete compact fixture contains the `new pane` header, heading, terminal
or agent field, directory button, `Terminal` action, send action, cwd, locality,
branch, mode switch (`Open an agent`/`Open a terminal`) and shortcut hint. Agent
mode also retains its picker and permission control. The 375 pt window is the
width boundary; content below the height boundary scrolls inside the chooser.

- width: `24 × 9 pt agent character + 124 pt controls/insets = 340 pt`
- height: `20 card + 26 header + 8 gap + 24 body inset + 24 heading + 54 section gaps + 150 form + 32 metadata + 64 compact footer = 402 pt`
- surface: 340×402 pt
- footprint with halo: 370×432 pt
- complete-fixture window height: 516 pt after the 84 pt shell overhead

The 370 pt footprint leaves 5 pt at a 375 pt window (4 pt in the measured pane
viewport after the window inset) and therefore never asks the chooser itself
to scroll sideways. At 375/390/430/768/1024/1440/3440, the complete fixture
fits at heights 812, 768, 736, 672, 640 and 568. At 480 and below, the body
scrolls vertically instead of clipping or shrinking controls.

The placeholder floor is a per-pane-ID presentation override. Its leaf keeps
the eventual terminal/agent kind for arrangement. The chooser never submits
the synthetic ID through `workspace.layout.set`; the engine's existing layout
validation would also reject it because it is not a live pane.
